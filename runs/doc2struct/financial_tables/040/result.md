## **Shareholder Return Incentive**

The Shareholder Return Incentive is directly aligned with shareholder interests as the incentive becomes vested only in the event shareholders gain at least an 80 percent return on investment. The Shareholder Return Incentive provides an equity grant of 1,000,000 PSUs to the CEO, based on the absolute TSR from the merger date to December 31, 2025.
